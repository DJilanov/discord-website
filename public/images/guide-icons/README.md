# Guide Icons

These 54 original bitmap icons were copied from the existing public KFC Tools
asset endpoint for the reviewed Forever snapshot `ba1427415d5f0d850e1f12a48a6b81e81b25a23cebf86923d1d7456eb4bf1cfc`.
They are used to identify the actual classes, talents and spells in the guides.
Game artwork remains Blizzard's property.

The source, snapshot, text-data attribution and individual asset checksums are
recorded in `content/class-guide-evidence.json`. The CC BY 4.0 attribution on that
data applies to the adapted talent and spell text, not a separate ownership
claim over Blizzard's artwork. `scripts/prepare-class-guide-evidence.ts` refuses
a different snapshot until it has been reviewed.
