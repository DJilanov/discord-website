# Forever Event Artwork

Generated on 3 October 2026 using the built-in image generation tool.
This is an original, text-free fan-art cover library, not official game imagery,
verified dungeon geometry, encounter art or evidence that a raid is playable.

The 50 full-resolution WebP covers total about 14.1 MiB. Encoding preserves the
generated composition and 1672 x 941 dimensions; no scene was cropped or drawn
over. The original 14 covers are unchanged; 36 new covers complete the named
inventory. PNG originals remain in Codex's generated-images directory. The
expedition, Alcaz Prison and Ragefire Chasm covers had unwanted faction
insignias removed through the built-in image editor.

## Preview

Open [the gallery](preview.html) directly in a browser. It works without a
server or JavaScript. The existing development server also serves it at:

```text
http://127.0.0.1:19300/images/raids/events/preview.html
```

Filters cover all seven event types. The gallery has no signup records,
synthetic attendance, external asset requests or tracking code.

Coverage was checked on 3 October 2026 against the
[Forever dungeon overview](https://www.wowhead.com/forever/guide/dungeons-overview-locations-details),
[returning dungeon quests and Dire Maul wings](https://www.wowhead.com/forever/guide/dungeons/every-dungeon-quest-location),
[three announced raids](https://www.wowhead.com/forever/guide/raids-overview-hub-dates-locations)
and [four battlegrounds](https://www.wowhead.com/forever/guide/pvp-overview-ranking-rewards).
The original seven named concepts were sourced from Blizzard's
[Forever announcement](https://worldofwarcraft.blizzard.com/en-us/news/24303862/world-of-warcraft-forever-whats-next).

There are 36 dungeon/wing covers: nine new Forever dungeons and 27 returning
Classic dungeon/wing profiles. This is an artwork count, not a claim of 36
separate instances. Scarlet Monastery has four wing images; Maraudon and Dire
Maul have three each; Blackrock Spire has two. Stratholme's routes share one city
cover. The raid inventory is Hyjal Summit, Barrow Deeps and Onyxia's Lair; the
battleground inventory is Darkspear Islands, Warsong Gulch, Arathi Basin and
Alterac Valley. No unrelated expansion raids or battlegrounds are included.

Appearance is generated interpretation, not copied or confirmed official
artwork. Beta details can change. No loot, bosses, instance identifiers, access
rules, release dates or game limits are inferred from these images.

The manifest records this reviewed coverage and its source links. Tests require
all named locations and wings, all seven fallbacks, unique aliases, decodable
nonblank WebP files below 500 kB each and a pack size below 16 MiB.

## Manifest And Prompts

[`manifest.json`](manifest.json) describes files, dimensions, alt text, event
types, matching names, reviewed coverage, sources and one fallback for each
type. This is a presentation contract, not a new selectable loot catalog or
event-availability registry.

For future automatic selection, match a normalized exact activity name within
the event type before choosing that type's fallback. Do not guess from title
substrings, keywords or an untrusted remote image URL. Aliases include common
abbreviations and straight/curly apostrophe variants. The ambiguous abbreviation
DM is deliberately not mapped to either Deadmines or Dire Maul. Unqualified
Scarlet Monastery, Maraudon, Blackrock Spire and Dire Maul use the Cathedral,
Earth Song Falls, Upper Spire and West-wing covers as visual defaults only;
these aliases do not select a gameplay wing. Hyjal artwork is a
Forever world-tree interpretation, not the TBC encounter from the reference.

All creation and correction prompts are recorded in
[`forever-event-artwork-prompts.json`](../../../../docs/forever-event-artwork-prompts.json).
Style: panoramic painted Warcraft-inspired environments, readable central
subjects, varied activity-specific lighting, and no baked-in event text.

## Discord Integration Boundary

This asset batch does not change the live event renderer, activity form,
Discord messages or publication rules. The post redesign can consume the
manifest after review.

Discord displays images through embed image fields or Components V2 media;
it does not support arbitrary CSS backgrounds behind live message text.
[Message media](https://docs.discord.com/developers/resources/message#embed-image-structure),
[V2 media gallery](https://docs.discord.com/developers/components/reference#media-gallery).

Use one wide cover near the event header in the V2 design candidate; keep
title, timestamps, roster and controls as native readable components. Classic
embeds have client-controlled image placement, which must be checked in actual
Discord desktop/mobile clients. Do not rasterize signups into an image.

Discord must be able to fetch the cover. A URL pointing to localhost on the
organizer's laptop cannot work for Discord's image service. Publish the static
assets with the website before referencing public HTTPS paths, or implement
reviewed bot-owned attachments in the scoped delivery transport. Do not silently
hotlink to another project or loosen the current source verifier.

Keep new covers optional until deployment verifies every selected image URL.
Missing artwork must not prevent an event signup or delivery. Format/source
migration and real-client review remain gates in the
[Discord experience plan](../../../../docs/forever-raid-discord-experience-plan.md).
