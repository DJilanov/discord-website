# Simulation Guide Icons

These are original game-icon bitmaps, copied without editing from the existing
simulator asset cache or the published client-reference asset service. They are
used to identify the actual classes, selected talents and equipped items.
World of Warcraft imagery remains Blizzard Entertainment's property; the
CC-BY-4.0 talent-data attribution does not relicense the images.

`content/simulation-evidence.json` records each filename's SHA-256. The importer
rejects unsafe names, unavailable assets and oversized payloads. No generated
replacement is substituted for an unknown game item.
